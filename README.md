# VendorIQ - AI Vendor Risk & Outreach Agent

Trust Every Vendor Before You Pay

## Live Demo
https://hariaharapandian33-bit.github.io/VendorIQ/

## Problem
Indian MSMEs face fake vendors, fake GST numbers, no trust before payment, and money loss due to vendor fraud.

## Solution
VendorIQ - Search, Verify, Trust in 10 Seconds
- Search any vendor by name
- Get Trust Score out of 100
- See GST, Company Details, Risk Level
- AI Agent sends personalized outreach

## How It Works
1. User searches vendor name
2. Checks company data, GST & financial health
3. AI calculates Trust Score
4. Green = Safe, Yellow = Medium, Red = High Risk
5. Contact with AI Agent

## Features
- Live Vendor Search
- Trust Score Engine
- Risk Detection
- AI Agent Outreach
